## moons-pack

A highly customised tech modpack.


#### Installation

To install simply download the [.mrpack file](/mrpack) and import in via the modrinth launcher.

To enable automatic updates, add the following line in the settings, under **Launch Hooks** -> **Pre-launch**:

```
java -jar packwiz-installer-bootstrap.jar https://moons-pack.jmcmoon.com/pack.toml
```

Remember to ensure you have the right RAM settings (I recommend 4GB).

I also recommend turning off the Distant Horizons and Iris mods if you have a bad computer.

The Lithosphere and Still Life mods are very heavy terrain generation, so you should replace them if you intend to play singleplayer.

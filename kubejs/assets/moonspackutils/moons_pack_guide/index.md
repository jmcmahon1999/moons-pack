# Welcome

Welcome to Moon's Pack!

This modpack is a highly customised tech modpack. Focused on making tech-mods feel like doing actual science, discovering new technologies and dimensions with research and experiments. Its 'Greg-ish' and grindy, its mainly built around Modern Industrialization and Applied Energistics 2, with some heavily customised parts of Oritech, Avaritia and Draconic Evolution to make the end game feel satisfying.

This modpack is in active development, and given the sheer amount of content, it is inevitable that you will stumble across broken recipes, bugs and balance issues. If you find any of these things, please don't hesitate to contact me on [Github](https://github.com/jmcmahon1999/moons-pack/issues) or Discord.

In particular, please look out for:
- Duplicate recipes (look out for the polymorph button to switch between recipe outputs)
- Missing recipes (items which don't appear to have a crafting recipe)
- Useless items (items with no recipe and no obvious purpose)
- Recipes which enable duping.

For more documentation check out the [Guides](guides.md) page and the [Features](features.md) page.

For an easier, less grindy experience, check out [Easy Mode](easy_mode.md).
